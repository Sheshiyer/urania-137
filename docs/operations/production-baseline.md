2. Consented relationship generation has a secure API but no reachable product caller.
3. The release script accepts untracked files and mutates tags/releases before deployment proof.
4. Required branch governance, preview D1 isolation, restore rehearsal, privacy export/delete, request bounds, CSRF, and alert delivery are incomplete.
5. The landing prototype is neither route-correct nor deployable across the Access boundary.
6. ISA/status/issue evidence contains false-complete or stale claims.
